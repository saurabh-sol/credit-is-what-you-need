# Provider logos

Monochrome SVG marks from [`@lobehub/icons-static-svg`](https://www.npmjs.com/package/@lobehub/icons-static-svg) v1.95.1 (MIT).
They are drawn through a CSS mask (see `src/components/model-logo.tsx`), so they take the color of the text around them.

The logos are trademarks of their owners and are shown only to identify which providers' models can be reached.
