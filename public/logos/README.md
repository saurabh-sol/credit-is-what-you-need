# Provider logos

SVG marks from [`@lobehub/icons-static-svg`](https://www.npmjs.com/package/@lobehub/icons-static-svg) v1.95.1 (MIT).

- `<name>-color.svg` is the maker's mark in its own brand colors, shown as-is.
- `<name>.svg` is the single-color mark. It is drawn through a CSS mask (see `src/components/model-logo.tsx`), so it takes the color of the text around it. Makers whose brand is a single color (OpenAI, Anthropic, xAI, Moonshot, Black Forest Labs, Recraft) only have this version.

The logos are trademarks of their owners and are shown only to identify which providers' models can be reached.
